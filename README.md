# Reto API 1 - Clima

Proyecto de diagnóstico y depuración en React.

## API utilizada
Open-Meteo

## Objetivo del ejercicio
El proyecto compila y se ejecuta, pero contiene errores funcionales deliberados en la lógica principal.

### Comportamiento esperado
- Buscar una ciudad.
- Usar el resultado principal de geocodificación.
- Mostrar temperatura correcta en °C.
- Clasificar correctamente el estado térmico.

## Reglas
- No instalar Axios ni otras librerías para consumir la API.
- Utilizar `fetch()` nativo.
- Identificar y corregir los errores funcionales.
- No reemplazar la API por datos escritos manualmente.
- Realizar pruebas antes y después de cada corrección.
- Crear commits separados para las correcciones principales.
- Subir la versión corregida a un repositorio propio de GitHub.

## Ejecución
```bash
npm install
npm run dev
```

## Entrega
- Repositorio propio en GitHub.
- README actualizado indicando qué errores encontraron y cómo los corrigieron.
- Mínimo 3 commits significativos.
- Evidencia de la aplicación funcionando.
